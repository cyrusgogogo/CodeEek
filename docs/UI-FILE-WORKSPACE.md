# IDE 文件与阅读工作台

## 范围与方向

当前源码把「阅读代码」组织为左侧文件目录、中央统一文档、右侧阅读列表的 IDE 工作台；代码浏览是默认入口，问题表单按需打开，选区可明确请求逻辑图。不替换 DSH 外壳，不改仓库读写边界、会话模型确认或批注提交协议；既有发布归档不是本工作区的实时映射。

按 `ui-ux-pro-max` 的开发工具方向实施，采用低干扰、代码优先的桌面布局：语义图标、稳定行高与缩进、清晰的文件身份、可见焦点、完整键盘操作、明暗主题 token 和减少动态效果支持。技能的整页推荐返回了偏 FAQ/文档落地页的结构，两次检索后仍不适合 IDE，因此**未将该输出保存为设计系统，也没有照搬落地页、外链字体或独立暗色调色板**。实际采用的是已核实适用于 Web 的 keyboard navigation / focus states / focus not obscured 建议，以及 React 的派生值和状态指导。

## 当前布局与核心流程

- **左侧文件目录**：桌面默认展开，可切换目录／字面量检索与批注；支持折叠、拖动、键盘和按钮在 200–420px 内调宽。保持仓库、文件名、父路径和选中状态可辨识；单仓不显示独立选仓条，多仓通过目录根节点切换，当前根以展开／选中状态标识；同名仓库可由物理路径与仓库身份区分。不再放置目录底部说明。检索输入框按 Enter 搜索内容，Shift+Enter 按路径查找，不显示搜索动作按钮，保留输入标签、键盘提示、加载／错误／截断反馈。
- **中央文档工作区**：初开仓库显示“选择文件，开始阅读”，不预先铺开大对话表单、步骤或说明；单击文件打开只读代码。文件与阅读文档使用同一排可关闭标签，源码与图／解释在中央切换，而不是挤成两块正文。
- **右侧阅读列表**：默认列出“阅读中”的会话和实际知识点；点击已有记录只打开，即使为空也不创建新会话。**新建阅读** 在中央打开仅存内存的临时阅读，确认发起分析或显式保存人工批注时才落盘，未发起草稿不入列表、不记作可恢复会话。底部“问题阅读”只打开当前记录。记录旁“归档”从默认列表收起记录，“已归档”可查看或恢复；归档期间禁止新分析，不删除产物或改变方法关联。追问区可折叠，历史、产物与设置不长期抢占代码空间。
- **有界文件标签**：最多 12 个，仅保留页面内存中的文件身份与位置；激活时重新完整读取并核验哈希、恢复各文件滚动位置。跨仓同名文件仍以仓库身份区分；关闭标签不删除文件。完整标签集合不写入浏览器源码缓存，也不承诺刷新后全部恢复。
- **选区逻辑图**：在已加载源码中手动选择方法／类文字，最多 8,000 个 UTF16 单位；右键或 Shift+F10 → **AI 生成逻辑图**。沿用实际会话模型与源码发送范围确认，Host 核验哈希、行列和选文后取证。方法优先有证据的控制流、分支、异常与返回，类按关键协作绘图；界面不自动框选完整符号；导师会读取所属完整方法／函数后归档，语义边界由模型识别，Host 核验版本、坐标和完整证据，不宣称 AST／静态调用分析。结果在中央阅读文档图优先展示，解释与证据随后；普通解释和后续追问不强制沿用绘图意图。
- **恢复与响应式**：Host 按会话保存当前代码／阅读文档类型及原有位置元数据，缺失字段的旧档案继续可用；不增加浏览器源码或对话持久化。恢复源码仍重新读取核验，不能伪造旧版本。窄屏目录与阅读列表按需变为抽屉，中央文档优先，可最大化代码；保留明暗主题、键盘焦点和减少动态效果。
- **安全边界**：保留只读、UTF-8、1 MiB 文件字节上限、路径／链接／文件身份检查和扫描预算。工作台一次完整打开额外受独立的 **20,000 行渲染上限**约束；任一上限超出时整份明确拒绝，绝不截断冒充完整文件，也不恢复分页。AI `reading_read` 仍是最多 400 行、100,000 字符的有界取证工具，不因 UI 完整打开而扩大；UI 浏览不生成工具证据。证据失效、人工批注复核规则不变。图须使用安全非空结构化 Mermaid，保留输入检查、SVG 清洗、受限 iframe 和源码回退；缺图或被安全校验拒绝的请求不能伪装成已完成逻辑图。其他上限见 [README](<../README.md>)，操作见 [使用手册](<USAGE.md>)。

### 完整文件与旧阅读位置

- Host 从一次 `readRepository` 的已核验字节返回完整连续行，`offset` 固定为 1；原字节 SHA256、字节数和总行数与同一读取结果绑定。Client 只发起一次文件请求，完整行数或连续行号不匹配时拒绝该响应，不递归补页、不拼接不同哈希的结果。重载及标签切换重新读当前版本，不把旧字节伪装成历史快照。
- 源码区不再提供“上一段／下一段／跳到行／跳转”工具栏；使用正常滚动连续阅读。搜索命中、证据和批注打开完整文件后本地定位；高亮仍须通过 SHA256 校验。
- 旧档案的 `offset` 作为行锚点加原页内滚动恢复；新位置保存 `offset: 1` 和完整文件内实际滚动。Host 对旧 Client 的 `offset`／`limit` 仍做原有输入校验，但它们不裁剪 UI 文件响应。旧版本或越界位置保持明确失效／待确认提示，不猜造源码、证据或选区，也不增加浏览器源码持久化。

## 方法级源码阅读关联

- **统一最小粒度**：代码解读至少是完整方法、函数或构造器等可调用单元；类／整文件可以是更大范围，整文件必须从开头覆盖到结尾。文档／数据文件豁免；未知编程语言不因为没有词法高亮而豁免。方法边界由模型结合完整源码识别，不使用 JS 专用正则冒充跨语言解析，也不宣称全语言 AST 证明。
- **可核验关联**：[代码单元模块](<../src/code-units.mjs>) 核验仓库归属、文件原字节 SHA256、UTF16 排他范围和连续完整读取证据。新知识点保存 `codeUnits` 的名称、类型、范围、结论与证据；本轮 `readingFocus` 只保留身份／版本／坐标，不能把选区或对话复制成浏览器缓存，也不能绕过取消、模型、版本或提交守卫。
- **源码专用显示**：打开文件时从同项目、同仓库和路径的阅读档案收集当前版本记录，跨阅读会话保留关联。只在真实源文件阅读器显示 AI 标记和轻量范围提示；笔记里的代码围栏不是该源文件快照，不附会方法已读状态。未知语法纯文本仍可显示有证据的范围标记。
- **悬浮与键盘**：鼠标停在实际方法代码／标记上或键盘聚焦标记，显示已有结论。标记点击预览，不任意打开某条历史；同范围的归档记录分组，显式“打开阅读”选择准确会话与知识点。支持触屏点击、向下键进入动作、Esc／Tab、外部点击与滚动关闭；没有 hover 请求模型，没有浏览器 Selection 改写。浮层可悬停并滚动，结论按 React 文本节点展示，不运行 HTML。
- **并存与失效**：AI 标记与人工批注使用不同栏位，保留真实行号、选区、连续滚动、字号和折行。旧哈希记录不猜新位置；没有代码单元范围的旧档案不伪造方法标记。显示范围只针对当前加载字节版本，不等于用户理解、实时文件监听或整仓语义保证；人工批注的独立 CAS／复核规则不变。
- **有界与兼容**：保留原五个工具和既有预算，新增字段采用旧档案兼容默认；空 `codeUnits` 和空内容维度不改变旧发布凭据的有效哈希。关联扫描／显示有上限，截断时明确说明可能还有记录；没有引入运行时解析器依赖、后台语义重绑或真实模型调用。

## 已实现

1. [有限静态映射](<../src/client/file-icons.mjs>)：准确文件名优先，再处理声明文件、配置文件等规则和扩展名；识别 Windows 分隔符与大小写。覆盖 TS/JS/React/Vue、Markdown、Java/Python/Go/Rust、JSON/YAML 等。未知文件使用通用图标。
2. [目录与阅读器](<../src/client/reader.jsx>)：语义文件夹及展开态、根目录身份、刷新目录、收起子目录、原生 Tab 和方向键/Home/End 导航。箭头导航只移动焦点，不偷偷读取文件；Enter/单击保留原生行为。未冒充实现完整 ARIA tree 合约。
3. [基础视觉样式](<../src/client/style.css>) 与 [IDE 布局](<../src/client/ide.css>)：保留统一 20px 目录图标、32px 目录行、细层级引导线、目录内多仓根节点导航、稳定的选中背景／加粗／侧边标记；中央采用更平直的文件面板和统一标签。单独展示文件名和完整父路径，长名称省略且保留 title，不挤坏操作区。
4. 窄屏两侧栏默认收起，以抽屉按需打开；中央文档保留主要空间，减少动态效果时关闭过渡。原有批注、选区、字号、折行与只读源码展示保留，源码按完整文件连续显示，不再提供页段／跳行工具栏。
5. SVG 来自审计过的有限本地列表；仓库文件名不能变成 SVG、HTML、动态 import 或资源 URL。不可信 HTML 仍只作为代码文本显示。

## 运行中 GUI 的验证边界

历史图标优化时只读访问过当时的 URL `http://127.0.0.1:50661/`，独立 Chrome 收到 DSH 的 `authentication required` 页面，没有可用的已认证浏览器上下文；这不是当前工作区的运行中 GUI 验收。因此**不能据此宣称当前登录 GUI 已安装或加载本次构建**。隔离浏览器测试也不代表真实登录端到端；当前改动不授权启动替代服务器、修改已安装 DSH、绕过认证或发起真实模型请求。

本工程源码与预构建插件不是已安装归档的实时映射。需要通过既有插件发布/安装方式更新运行中版本，遵从安装器的刷新或完整重启提示；没有核实 `dev:web` watcher，故不承诺 HMR。
