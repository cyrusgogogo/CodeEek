# 五分钟开始阅读代码

先按 [安装手册](<INSTALL.md>) 安装并启用插件，目标 DSH 为 `0.2.1-rc.2`。完整安全边界和上限见 [README](<../README.md>)。

> 本手册描述当前源码工作区的代码优先 IDE、逻辑图与方法级源码关联界面。既有 0.1.7 发布归档保持原快照；需要将当前源码以新版本构建、打包并安装，不能只刷新网页或另开服务器。

## 1. 确认已就绪

打开 DSH 左侧 **阅读代码 → 更多 → 安装与使用**。确认 Client 与 Host 版本一致，仓库列表已加载完成。加载失败不是空列表，应先重试连接或检查安装，不要反复创建。

在 DSH **设置 → 模型**配置提供方。本插件不附带模型或运行本地模型的程序；“本地”只是你选择的提供方配置，不能仅凭名称推断数据完全不出网。

## 2. 打开仓库与开始阅读

1. 点击 **打开本地仓库**，或从 **更多 → 打开其他仓库** 进入。
2. 从已有工作区添加仓库，或选择本机绝对目录；可以联合绑定 1–12 个仓库。自动使用目录名称，不必填写项目名或仓库名。
3. 核对路径与范围：仓库不能重复、互相嵌套、与阅读档案目录重叠。只支持真实本地目录，不接受符号链接／junction 或 UNC。
4. 点击 **打开仓库**。此时只保存仓库绑定，阅读会话仍是临时草稿，**没有向模型发送请求**。

仓库绑定不可变，切换普通 DSH 工作区不会重新绑定。工作台按 **左侧文件目录 → 中央文档 → 右侧阅读列表** 排列；桌面默认展开目录，中央先显示 **选择文件，开始阅读**，没有自动打开的大对话输入框。单击文件即可在中央只读阅读，不调用模型。

右侧 **阅读列表** 默认列出 **阅读中** 的会话。点击已有记录只在中央打开，即使记录为空也不会另建会话；**新建阅读** 则在当前仓库打开临时阅读表单，不必重复选择目录。仅填写目标、选择模型、浏览代码或在确认框选 **暂不发送** 都不保存会话；确认发起分析或显式 **保存批注** 后，才保留这条阅读。未发起的临时阅读不进入列表，离开后不恢复。临时阅读提示位于中央底部状态栏；底部 **问题阅读** 只打开当前记录。需要新增／替换仓库时打开其他仓库，保留原证据与历史。

窄屏用两侧抽屉按需访问目录与阅读列表；选中文档后优先保留中央阅读空间，可折叠侧栏或最大化代码。

若提示“项目已保存，后续会话步骤未完成或结果未确认”，先刷新查看仓库列表，不要重复创建；使用该仓库的 **＋ 新阅读会话** 继续。

## 3. 确认实际模型与数据传输

在中央底部、问题阅读表单或后续追问区选择本会话的 **阅读模型**，列表按提供方分组。旧会话保留实际选择，不套用新设置。

**更多 → 阅读设置**只保留两项：默认阅读代码模型、插件档案位置。默认模型保存到插件档案根，只用于之后新建的阅读；保存设置不创建会话、不请求模型，也不修改 DSH 全局默认。选择 **跟随 DSH 默认**可清除插件覆盖。当前会话仍可单独选模型；已保存模型不可用时会明确报错，不偷偷换成其他提供方。设置页 **重新加载**只重新读取设置和模型目录，保存冲突或网络结果未确认时先用此入口核对，不重复点保存。提供方端点仍在 DSH 模型设置中管理。

- 没有可用模型时，先去 DSH 配置，再从阅读设置重新加载。
- 目录加载失败或部分提供方失败，不会自动改选提供方。
- 分析中可回看已有知识点，不能改变本轮模型。导航与内容维度切换不会调用模型。
- 首次调用、模型／提供方或绑定范围变化会弹出 **确认源码发送范围**。实际接收端点未由接口提供，不要仅凭显示名称判断本地部署。
- **模型服务可能接收本轮读到的源码片段、问题与对话。** 不确定能否外发时先不要确认；本插件不提供通用秘密扫描或 DLP 保证。

## 4. 从问题或具体代码开始

### 生成选区逻辑图

1. 从左侧目录打开文件，在中央**手动选中方法或类的文字范围**，不超过 8,000 个 UTF16 单位，且仅在已加载文件内选择。界面不会自动替你框选完整符号；若只选了片段，导师须继续读取所属完整方法／函数后再归档。完整范围仍须满足既有文件和证据预算。
2. 右键或 Shift+F10 打开菜单，选择 **AI 生成逻辑图**；先确认会话模型，首次调用或模型／绑定变化时核对 **确认源码发送范围**。仅浏览、选择代码或打开菜单不发送请求。
3. Host 重读并核验文件 SHA256、行列及选文，创建证据后才接纳分析。导师读取完整代码单元和必要上下文：方法优先用流程图呈现关键判断、分支、调用、异常与返回，类按实际职责和协作使用类图或流程图。重要关系须有证据，不把图或 AI 识别的方法边界当作 AST／编译器证明。
4. 完成后在中央阅读文档中**先看图，再看解释、结论与证据**；文件标签仍可切回对照。缺图、空图或触发安全校验的图不能作为已完成逻辑图归档；取证不足时应继续取证或明确说明失败。图渲染失败会保留源码回退，不等于图已通过完整语法或语义证明。

### 从问题出发

先用底部 **问题阅读** 打开当前记录，或右侧 **新建阅读** 创建独立记录，在中央 **从问题出发** 下填写阅读目标，例如：

> 用户提交订单后，系统怎样校验输入并完成支付？

也可使用“了解整体业务”“寻找功能入口”填入示例再修改。点击 **开始阅读**并确认范围后，首次问题成为阅读主题。未填写问题的记录使用仓库名称，不需要再命名。

### 只解释代码或带着选区追问

选中文本后使用 **让 AI 分析选中代码／解释这段**，或在中央阅读表单选择 **从代码出发 → 选择代码**。导师先识别并完整读取所属方法／函数，再解释实现、追踪项目内必要的上下游调用及相关业务，不先做全仓库业务发现；非代码文件沿用内容阅读。也可先用 **用于追问** 固定选区，补充具体问题后发送；临时浏览其他文件不会替换它。

普通解释和后续追问不因上一轮生成过图就强制再次绘图。导师有界检索、读取并发布知识点，不运行项目、调用 shell 或修改源码。每轮解释一个知识点，之后等待你决定。

## 5. 生成后按内容维度查看

五个内部维度是导师组织内容的设定，不是必须完成的步骤。页面不显示固定阶段导航；只有实际生成了对应内容，才出现维度切换。

| 内容维度 | 何时使用 |
| --- | --- |
| 业务概览 | 目标宽泛、需要先明确仓库用途时 |
| 业务解释 | 解释业务角色、输入输出和规则时 |
| 调用链 | 跟踪真实入口、调用方和被调用方时 |
| 代码逻辑 | 解释选区、关键分支、事务和异常时 |
| 理解自查 | 你主动要求验证理解时 |

代码阅读优先代码逻辑、必要调用链和相关业务；明确问题优先直接回答，不要求先做业务发现。维度切换只查看已归档内容，旧档案没有结构化维度时仍展示完整正文，不伪造空维度。

**继续阅读**或明确发送追问才会启动下一轮。“深入”只把建议放入输入框，仍由你确认发送。**标记已理解**仅记录你的主动选择，查看不代表理解。返回原路线可恢复知识点、源码与正文位置。

**停止分析**等待后端确认结束或空闲，不只停止动画。失败保留已完成内容；**重试本次分析**保留原模式、问题与父知识点，网络结果未确认时重放原请求 ID，应先刷新核对。

## 6. 回到代码与证据

- 左侧 **文件目录** 在桌面默认展开，可切换目录／批注；检索框中 **Enter** 搜索内容，**Shift+Enter** 按路径查找，均为有界字面量匹配。可折叠，拖动／键盘／按钮在 200–420px 内调宽，不运行正则或代码。
- 点击知识点中的引用在**中央文件标签**定位源码；切回阅读标签继续看图或解释。仓库、相对路径、行范围、符号文本线索和文件 SHA256 同时展示；代码区可最大化、调整字号和折行。当前接口不提供 Git 分支／提交，不把内部状态版本当源码版本。
- 文件标签最多保留 12 个，仅在当前页面内存中维护。切换时重新读取并按已保存哈希核验，恢复各文件的行锚点及滚动位置；关闭标签不删除文件，也不清除已归档阅读内容。不是把 12 份源码存入浏览器持久化存储。
- 打开时会重新核验源码。源码改变或不可读取，旧证据会显示失效；当前可读代码不等于旧版本，须重新取证再下结论。
- 文件列表／搜索结果保留命中时的仓库身份，即使随后点击其他仓库根，也不会把同名文件当成另一个仓库。单仓没有独立选仓条，多仓通过目录内根节点切换。
- 源码与知识点代码块使用深色高对比面板：紫色关键字、绿色字符串、橙色数值、蓝色函数／标题和灰蓝色注释。颜色只是词法辅助，不是类型分析或真实性证明。
- 左侧显示真实源码行号；代码块右上角可切换 **自动折行**。浏览器允许时会记住偏好；它不修改文件，也不改变证据范围。
- 按文件名或代码围栏语言选择语法，不识别、过长或解析失败时显示纯文本，原始字符仍保留。
- 出现截断时缩小范围或给出已知入口。页面一次完整加载 1 MiB、20,000 行以内的文件，超限整份拒绝、不显示部分源码；Agent 取证单次仍最多 400 行、100,000 字符，搜索和枚举也有预算；“没找到”不代表源码中不存在。

符号线索是文本匹配，不是 AST、静态调用图或编译器证明。AI 的业务解释仍需你核对事实、推导和假设。

## 6.1 文件阅读、选区分析与批注

1. 打开左侧 **文件目录**，选择当前项目绑定的仓库并逐层展开。单击文件直接在中央文档标签打开；阅读内容保留在自己的标签中。源码没有编辑、保存或执行功能。窄屏目录与阅读列表按需用抽屉展开。
2. 源码可调字号和折行。先选中代码，再点 **用于追问**，将仓库／文件／哈希／行列范围固定在阅读文档输入框上方；临时打开别的文件不会悄悄替换此上下文。可显式移除选区，或 **返回原阅读路线** 恢复原知识点与源码位置。
3. 支持 1 MiB 内普通 UTF-8 文本，按文件名识别代码类型；未知语法显示纯文本。HTML/SVG/脚本只作为源码着色，不作为网页运行；二进制、不支持的编码或过长单行会明确拒绝，不偷偷改编码。
4. 文件一次完整加载，可直接滚动到后面的代码，不再使用上一段、下一段或跳行分页。选择不超过 8,000 个 UTF16 单位的代码，右键或 Shift+F10 打开菜单；方向键选择、Enter 执行、Esc 关闭。
5. **AI 生成逻辑图** 与 **让 AI 分析选中代码** 都沿用当前会话模型、强制从选区代码出发。Host 重新核验哈希及选文、创建证据；导师按需读取必要上下游与业务背景，不进行无关全仓发现。模型服务可能接收这些内容。结果进入知识点／对话留痕，不直接成为已确认批注，也不要求完成其他阶段。
6. **添加代码批注**打开本地草稿。填写说明后保存；选区、附近上下文、原字节 SHA256 和 UTF16 行列写入该阅读会话的 `annotations.json`，不改变仓库。该文件是含代码的阅读产物，不是完整文件备份，不会自动发送给模型。
7. 源码移动后点击 **重新加载文件**：只有选文和双侧上下文能可靠匹配时才提供候选；任何文件哈希变化仍需你点击 **我已复核，确认本版本**。候选不会显示成已确认的行边批注。
8. 选区被改动、上下文变化、多个匹配或路径移除时，保留旧快照，不把批注硬挂在旧行号处。切换左侧 **批注** 并勾选 **本会话全部**，选定批注；打开目标文件选中新代码，再点 **重新绑定到当前选区**。跨文件/仓库的重新绑定也必须由你明确选择，旧记录在历史中保留。

位置不等于语义有效：颜色和“本版本已确认”仅针对该文件的锚定版本，不证明整仓业务语义没变。已观察到的变化即使回滚也不会自愈；只有人工确认／重绑清除。没有实时文件监听、Git 世系追踪或未观察变化的保证；重新打开/加载时检查，提交分析或批注前 Host 还会重新核验。

批注独立 CAS 与幂等提交，不复用阶段版本；并发修改冲突请刷新后复核。每会话最多 100 条批注、400 次提交、8 MiB 侧车，每条最多 20 个绑定版本、正文 4,000 字符。侧车是原子提交的权威记录，audit 中 `*-attempt` 只表示尝试，不等于成功；仍只支持一个 Host 写同一档案根。

## 6.2 方法级解读与源码标记

代码解读的最小单元是**完整方法、函数、构造器等可调用单元**，不把其中几行语句当成完整方法。类和整文件可作为更大的阅读范围；文件级范围必须覆盖整文件，没有显式方法的模块可按完整文件阅读。文档／数据文件不受方法粒度限制。所有编程语言使用同一种范围与结论记录，未知语法即使显示纯文本也不自动豁免。

1. 选中代码并请求解释或逻辑图后，导师先识别所属完整单元、补读完整范围，再归档名称、源码版本、行列、结论和证据。Host 校验同版本证据连续覆盖完整范围，并包含本轮明确选区；取证不足不能冒充完整方法。**语义边界由模型识别，不是全语言 AST 或编译器证明。**
2. 打开或重新加载源码文件后，在当前阅读项目内跨会话显示已有 AI 解读。行号栏的 **AI 标记**和范围提示对应当前加载文件的 SHA256；完整文件内滚动仍可查看所属方法的解读。
3. **鼠标停在方法代码或 AI 标记上**，或用 Tab 聚焦标记，预览已有结论。点击标记只打开预览，不任意选择历史记录；同一范围的多次解读分组显示。预览里的 **打开阅读** 精确打开对应会话和知识点，即使它不是最新一条。
4. 悬浮预览不请求模型、不改浏览器选区、不将源码或结论保存到浏览器持久化存储。键盘可用向下键进入预览动作、Esc 关闭；触屏可点击标记后操作。滚动、改变文件／会话或打开代码菜单会关闭预览，避免遮挡当前操作。
5. **已有 AI 解读不等于你已理解**。类或文件概览也不等于其所有成员方法已读；只显示明确归档的范围与结论，主动理解标记仍独立保留。
6. 源码哈希不同时，旧解读只保留在历史中，不猜新位置、不标到当前旧行号。旧档案没有完整代码单元范围时不自动补造，需重新阅读建立关联；达到关联检索／显示上限会提示“截断”，不能据未显示断言从未读过。

核验针对**当前加载的单文件字节版本**，不是整仓语义保证；其他文件变化仍可能影响结论。没有实时文件监听、自动语义重绑或全语言静态解析。人工批注的历史与复核流程仍独立，规则不变。

## 7. 查看与带走档案

- **中央阅读文档**：一次聚焦一个问题；逻辑图请求先显示图，普通解释以摘要／结论优先，随后核对证据、推断与待确认部分。
- **历史追问与对话记录**：知识点下折叠收纳，按问题摘要定位；旧记录没有可靠父知识点字段时显示为会话记录，不臆造关联。完整记录保留分页。
- **右侧阅读产物**：查看数量、格式和原目录；**导出档案** 仍在固定目录生成汇总 Markdown，不写回目标仓库。
- **阅读设置**：仅设置默认阅读代码模型，显示插件档案根目录；默认只影响新建阅读，已有会话仍在底部单独切换模型。
- **保存阅读位置** 或切换主题：把知识点、查看与理解标记、源码身份／版本／位置，以及中央当前显示代码还是阅读内容保存在原 Host 会话中；兼容旧档案。多文件标签是页面内存状态，不保证刷新后完整恢复全部标签。源码需重新打开核验当前版本，不能恢复不存在的历史字节。
- Mermaid 支持时序、流程、类、状态、ER 图；无法渲染时保留源码回退，危险 HTML／资产／点击指令会拒绝。内嵌 Mermaid 保存在笔记里；只有结构化图字段才额外生成独立 `.mmd`，不一定每张图都有单独文件。

默认档案位于 Host 的 `DSH_HOME/code-reading`，未设置时为用户主目录的 `.dsh/code-reading`。以 **安装与使用 → 诊断信息** 显示的实际位置为准。档案可能包含代码片段，不是加密保险库；停止阅读并退出 DSH 后再备份整个目录。

## 8. 退出、恢复与清理

关闭或重新打开阅读面板后可从右侧阅读列表继续已保存的会话；未发起的临时阅读不会恢复。普通工作区切换不改变绑定。若浏览器不允许保存本地偏好，仍可从项目列表手动恢复，Host 档案不依赖 localStorage。

在右侧记录旁点击 **归档**，会话从 **阅读中** 收起，但知识点、证据、对话、人工批注及阅读位置全部保留。切换到 **已归档** 可以查看内容，点击记录旁的 **恢复** 或正文提示中的 **恢复阅读** 后可继续提问。归档不改变方法标记的历史关联，不调用模型；本轮仍在分析时需先停止或等结束。既有空记录不会被自动删除，也可以手动归档。归档／恢复使用独立版本校验，若另一页面已更改状态，先刷新核对。

顶部仓库选择 → **管理仓库…** 中可点击 **删除仓库**，确认后从仓库选择与阅读列表移除整个阅读项目；多仓库项目会一起移除，不改单个绑定。**不会删除磁盘源码目录，也不会删除原知识点、证据、对话、批注和阅读位置档案**。项目有任何阅读正在进行时须先停止或等结束；确认框可取消，不会调用模型。移除后旧页面与工具不能继续使用该绑定，重新打开同一目录会新建项目，不自动合并旧记录。

停用／卸载不删除档案；重新启用时保留同一数据根。改变数据根不自动迁移旧目录。插件不提供磁盘目录删除／项目迁移 UI，也不提供跨进程同时写同一档案根的锁保证。

遇到 Host 未就绪、版本不一致、认证失败、无模型、旧证据、审计损坏等问题，请按 [安装手册的按症状排障](<INSTALL.md#6-按症状排查>) 处理。不要为了继续阅读而放宽工具白名单、批准任意写入或伪造审计记录。
