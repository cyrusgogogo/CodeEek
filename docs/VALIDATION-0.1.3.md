# 阅读代码 0.1.3 · 配色与代码阅读验收

日期：2026-10-15。目标兼容声明：DSH `0.2.0-rc.2`。

## 结论

- 页面配色与代码显示改造完成，源码 **85 项测试通过，0 失败、0 跳过**。
- 工作区 Client 和真实发布归档内 Client 均通过原有 22 项隔离浏览器场景，以及新增代码可读性检查。
- 已通过当前 DSH 的 Bundle Manager 将桌面 profile 从 `0.1.1` 更新并启用为 **0.1.3**；实际安装目录的 **17 个文件逐字哈希匹配正式 tarball**。
- 安装器返回 **`restart-required`**。这证明安装和启用配置已保存，**不代表当前进程已加载新版**。尚需用户完整退出并重新打开 DSH，再确认 Client／Host 都为 `0.1.3`。
- 本轮没有为配色验收发送真实阅读模型请求；浏览器截图使用虚构订单／支付夹具，不是当前登录 GUI 的截图，也不是用户项目源码。

## 改进内容

1. 页面沿用 DSH 原生明暗主题令牌，增加背景分层、当前会话提示和更清楚的标题层次，不覆盖全局主题。
2. 五阶段使用带文字的编号色块；只读状态、证据标签和事实／推导／假设采用不同语义色，仍保留文字说明。
3. 源码证据与知识点代码围栏共用深色高对比代码面板，代码为 `13px / 1.8` 行高，具备行号、独立滚动和自动折行。
4. 证据从实际行号起算；知识点中的普通代码片段从片段第 1 行起算，不伪装成文件位置。折行只影响显示，不改写源码或证据范围。
5. 按明确语言或文件名选择精选语法，包括 Java、JS／TS／JSX／TSX、Vue／XML、Python、SQL、PowerShell 等。不进行顶层内容猜测。
6. 先整段分词再按行呈现，保留跨行注释／字符串上下文。超过 60,000 UTF-16 长度单位、未知语言、解析或保真校验异常时回退纯文本。
7. 只将公开 HAST API 的文本 token 与固定白名单样式类交给 React，不使用 HTML 注入或执行代码。Mermaid 继续走原有严格校验、SVG 清洗和受限 iframe。
